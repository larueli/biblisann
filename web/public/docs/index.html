Biblisann API

The REST API is described by an OpenAPI document generated from the server code. Pick the viewer you like; every one runs from this server, nothing is loaded from a third party.

Interactive documentation

  • Swagger UI: browse and try requests
  • Redoc: three-panel reference
  • Stoplight Elements: reference with a request console
  • Scalar: modern reference and client

The specification

  • OpenAPI 3.1 (JSON) and YAML
  • OpenAPI 3.0.3 (JSON) and YAML for tools that do not read 3.1 yet

Authenticate with a personal access token (Authorization: Bearer bb_pat_…), created in Settings. See also the MCP endpoint for AI assistants.
