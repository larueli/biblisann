Biblisann

Where are my books? Do I already own this one? Who has it?

A self-hosted manager for your physical library, with an offline barcode-scanning app, a REST API and an MCP server.

Get started Source on GitHub

Scan and own

Scan a barcode in a shop, even offline, and know at once whether you already own the book, in any edition.

Organise and lend

Places, shelves, reading status, lists, series, and loans with reminders.

Yours to run

One static binary and PostgreSQL. Docker, Compose or Kubernetes. AGPL-3.0, no lock-in.

Open by design

OpenAPI 3.1 API, an MCP server for your AI tools, OIDC and passkeys.
